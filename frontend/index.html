Mettre à jour le site

Récupérer le frontend et le backend depuis la branche main de GitHub ?

Les textes, les fichiers JSON et les images seront conservés. L’édition sera suspendue pendant l’opération et le site pourra être brièvement indisponible au redémarrage.

Vérification du serveur…

  1. Téléchargement
  2. Vérification du code
  3. Sauvegarde et installation
  4. Redémarrage du serveur
  5. Vérification du site
  6. Mise à jour terminée

Retour en arrière et sauvegardes

Si le redémarrage échoue, une restauration de la version précédente est tentée automatiquement.

Pour une restauration manuelle, demander à la personne qui gère le serveur d’arrêter PM2, de sauvegarder les JSON et images actuels, puis de consulter le fichier transaction.json du déploiement. Les anciens dossiers portent les noms previous-frontend et previous-backend.

Conserver les JSON actuels lors du retour au code précédent, ainsi que data/uploads/. Rétablir la version dans data/release.json, retirer le verrou data/update.lock seulement après vérification, puis relancer PM2.
